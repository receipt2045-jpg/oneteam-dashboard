💬 라이브 채팅 말풍선

미트 채팅에 올라온 최근 3개를 항상 위에 떠 있는 작은 창에 크게 보여줘요.
화면 공유를 '전체 화면'으로 하면 유튜브 송출·녹화본에도 같이 나가요.

① 한 번만: 아래 분홍 버튼을 크롬 위쪽 북마크바로 끌어다 놓으세요.
(북마크바가 안 보이면 Ctrl + Shift + B)

💬 말풍선

② 강의할 때
  1. 미트에 들어가서 오른쪽 아래 채팅(말풍선) 버튼으로 채팅창을 열어요.
  2. 북마크바의 💬 말풍선을 눌러요 → 미트 화면 왼쪽 위에 분홍 '💬 말풍선 띄우기' 버튼이 생겨요.
  3. 그 버튼을 누르면 작은 창이 떠요. 창을 PPT 오른쪽 아래 구석으로 옮기고 크기를 맞춰요.
  4. 화면 공유는 '전체 화면'으로 해야 말풍선이 같이 나가요. (창이나 탭만 공유하면 안 보여요)
  5. 질문을 다 읽었으면 창의 '비우기'를 누르면 화면이 깨끗해져요. 새 글부터 다시 떠요.

미트를 새로고침하면 말풍선이 꺼져요. 북마크를 다시 누르면 돼요.
